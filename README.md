## ❓ [05] FREQUENTLY ASKED QUESTIONS (FAQ DECK)

```
 ┌──[ 💡 INTERROGATION LOGS & PROTOCOLS ]───────────────────────────────────────────────────────┐
```

<details>
<summary><b>[Q-01] How does Lynqo operate without an internet connection?</b></summary>
<br/>

> Lynqo spins up an ultra-fast compiled Rust HTTP & WebSocket server locally on port `7432`. Any laptop, tablet, or phone connected to the same Wi-Fi router or hotspot communicates directly peer-to-peer over the LAN at the maximum speed of your local router hardware. No internet packets are dispatched to external servers.
</details>

<details>
<summary><b>[Q-02] Do I have to upload gigabytes of video footage?</b></summary>
<br/>

> **Never.** Lynqo eliminates uploads entirely. Videos are streamed directly out of your local hard drive / NVMe SSD buffer via byte-range requests. Reviewers open a lightweight web page that requests frames straight from your machine.
</details>

<details>
<summary><b>[Q-03] How secure is my footage and clipboard data?</b></summary>
<br/>

> **100% Zero-Knowledge.** Your creative assets and clipboard clips never touch a third-party cloud database. Data stays strictly inside your local network perimeter unless you manually activate an encrypted Cloudflare WAN Tunnel for remote collaborators.
</details>

<details>
<summary><b>[Q-04] Which operating systems and client devices are supported?</b></summary>
<br/>

> The Lynqo desktop workstation server is fully supported on **macOS (Apple Silicon & Intel)** and **Windows**. Collaborators and client reviewers need zero software installed—they connect from any web browser on macOS, Windows, Linux, iOS, or Android.
</details>
